# LiE

A feature-rich Minecraft mod that expands the game with new mechanics, content, and gameplay improvements.

## About

**LiE** is a Minecraft mod designed to enhance the overall gameplay experience by introducing new features and systems that build upon the game's foundation. The mod adds fresh content, improves existing mechanics, and creates new opportunities for exploration, progression, and creativity.

Whether you're starting a new survival world, building massive projects, or simply looking for something new to discover, LiE aims to make Minecraft more engaging and enjoyable without losing the charm of the original game.

## Features

* New gameplay features
* Additional mechanics
* Quality-of-life improvements
* Enhanced exploration and progression
* Regular updates and improvements

## Installation

### Fabric

1. Install Fabric Loader.
2. Install Fabric API (if required by your version of LiE).
3. Download the latest release of LiE.
4. Place the `.jar` file into your `mods` folder.
5. Launch Minecraft.
